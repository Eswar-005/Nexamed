# Nexamed — Digital Healthcare Portal

Nexamed is a comprehensive digital healthcare platform bringing together generic medicine search, disease encyclopedia, symptom checker, 24x7 pharmacy locator, live blood bank stock, NOTTO organ registry, WHO health news, patient profile, and 1-tap emergency SOS.

## Tech Stack
- **Frontend**: React 19 + Vite + Lucide Icons + Leaflet Maps
- **Backend**: Node.js + Express + SQLite3
- **Localization**: Multilingual (English, Telugu, Hindi, Tamil, Kannada) with Web Speech Voice Recognition & Audio Readout

## Getting Started

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```
